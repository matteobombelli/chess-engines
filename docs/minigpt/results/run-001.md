## Run incidents

- **Step 2000 and step 3000 — segment identity refusals.** Uncommitted
  worktree edits (a parallel implementation task, then the agent-worktree
  directory itself) tripped the per-segment byte-identical-worktree check.
  Both recovered with `recover` + `resume` from the segment checkpoint;
  ~20 minutes of GPU time lost, no training state lost. Fixes: all
  parallel work moved to an excluded worktree; `.claude/` added to
  `.git/info/exclude`.
- **Step ~16500 — trainer killed externally.** The harness task carrying the
  trainer was stopped, taking the process with it mid-segment. Recovered
  cleanly; relaunched detached (`setsid`) so external task management cannot
  reach it.
- **Steps ~70000–77000 — VRAM overflow into shared memory.** The largest
  length-bucket at micro-batch 64 exceeded 8 GiB (reported 9.19 GB), which the
  WSL2 CUDA driver absorbed by spilling to system memory at ~35% throughput
  cost instead of failing. Training was unaffected otherwise. A future fork
  should cap the top bucket's micro-batch.

## Final model

Best validation checkpoint = final step (77,000; no early stop):
validation loss **1.4234**, perplexity **4.15**, top-1 **53.4%** —
above the ~50–53% Maia-class band, consistent with the larger model,
~10× corpus, and whole-game context.

Export: ONNX opset 17 fp32, dynamic sequence axis. Torch↔ORT parity max-abs
7.6e-6 (tolerance 1e-3) across T ∈ {1, 4, 64, 256}, re-verified from Rust with
the same fixtures. Deep verify: 7 artifacts checked, clean.

## Calibration and claims

Same method and inputs as the other engines: `chesscom-30-0-refined.jsonl`
corpus, Stockfish 17.1 at 100k nodes/search, sample seed 1, cluster bootstrap
over players.

- **Chess.com 30+0 equivalent: 1928** (95% player-bootstrap interval
  **1610 to at-or-above 1999**), fit R² 0.63, 1,930 analyzed positions from
  1,737 games. Artifact: `runs/minigpt-30-0.json`.
- Context (move-quality labels of that date): Random <400 · Depth-3 ≈1640 ·
  AlphaMini ≈1970 · Minimax-9s ≈2050. The site now displays full-game ladder
  ratings instead; MiniGPT rates 1395 there (`docs/ratings/full-game-elo.md`).
  MiniGPT sits within AlphaMini's interval while moving in ~13 ms on CPU
  versus AlphaMini's 9 s / 10,000-simulation search.
- Measured at the served configuration (temperature 0.5). Greedy decoding
  (τ=0) is untested on this scale and may differ.

## Limitations

- Move-quality calibration, not full-game ratings; it does not measure clock
  handling or resignation.
- No search: no tactical verification beyond what the policy has absorbed;
  known GPT-chess weaknesses (long endgame conversion, repetition toward
  draws in won positions) appeared in the pilot's arena draws.
- Games beyond 254 plies lose truncated history (ctx 256); legality is still
  Rust-enforced.
- Single run; no seed-variance estimate.
